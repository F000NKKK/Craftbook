# Craftbook — кратко по-русски

Craftbook — наши стандарты разработки на Rust для всех проектов. Полный текст
на английском в [`rust/`](rust/): его читают и люди, и агенты. Стандарт
написан с нуля, по строгости как .NET Framework Design Guidelines, с DDD как
архитектурным методом. Текущий код проектов не образец, а то, что меряется по
стандарту; разница оформлена как план миграции в [`adoption/`](adoption/).

## Главные числа

| Что | Цель | Жёсткий предел |
|---|---|---|
| Строк кода в файле (без тестового модуля) | ≤ 250 | **400** |
| Строк во встроенном `#[cfg(test)] mod tests` | ≤ 150 | **150**, дальше `tests.rs` |
| `lib.rs` / `mod.rs` модуля с подмодулями | ≤ 60 | **100**, только `mod` и `pub use`, без логики |
| Файлов в одной папке модуля | ≤ 7 | **12** |
| Строк в теле функции (и в тестах) | ≤ 25 | **50** |
| Параметров, включая `self` | ≤ 4 | **5** |
| Вложенных блоков в методе или тесте (в свободной функции +1) | ≤ 2 | **3** |
| Покрытие строк: shared kernel / domain / app / адаптеры | | **95 / 90 / 85 / 70 %** |
| Покрытие изменённых строк в PR (shared kernel, domain, app) | | **90 %** |

## Файлы и подмодули

- Один главный элемент на файл, файл назван по нему (`render_graph.rs` →
  `RenderGraph`), как «один тип — один файл» в C#. Рядом можно держать только
  его спутников: ошибку, билдер, итератор, приватные помощники.
- Модуль становится папкой, когда файл подходит к 250 строкам и у него больше
  одной причины меняться, когда у трёх файлов общий префикс (`mesh_*.rs` →
  `mesh/`), когда есть варианты по платформе или числовому типу, или когда
  тесты больше 150 строк.
- Стиль один: `foo/mod.rs`. Никаких `utils`, `helpers`, `common`, `types`:
  делим по ответственности, а не по виду элементов.

## Функция или метод

Порядок вопросов (первое «да» решает): меняет или читает приватное состояние
и охраняет инвариант → **метод**; создаёт тип → **ассоциированная функция /
`From`**; есть явный субъект → **метод**; все входы равноправны
(`distance(a, b)`) → **свободная функция** (доменный сервис); работает с
внешним миром без своего состояния (`git::status::read(root)`) → **свободная
функция в именованном модуле**; нужно несколько взаимозаменяемых реализаций →
**трейт**. Пустая структура ради группировки функций (`struct GitService;`)
запрещена: это менеджер под другим именем.

## Нейминг

Слова из глоссария контекста (DDD ubiquitous language). Полные слова без
сокращений, акронимы как слова (`GpuDevice`), без `Manager`/`Helper`/`Data`/
`Info`, без повтора модуля в имени (`audio::streaming`, не
`audio::audio_streaming`), геттеры без `get_`. Таблицы шаблонов имён для
типов, функций и тестов в [главе 3](rust/03-naming.md).

## Архитектура (DDD)

Один ограниченный контекст = один domain-крейт плюс app и адаптеры. Слои:
interface → app → domain ← infra, и все могут зависеть от shared kernel;
зависимости направлены только внутрь. Порты (трейты) объявляет внутренний
слой: порты ввода-вывода — app-крейт, порты без I/O (часы, генератор id) —
domain; адаптеры их реализуют. Домен не знает про драйверы, `tokio`, файлы
и процессы. Value object, entity, aggregate, domain service,
domain event, порты с фейками и контрактными тестами — с примерами на Rust в
[главе 7](rust/07-architecture-ddd.md).

## README

У продукта два файла, `README.md` и `README.ru.md`, одной структуры: шапка с
бейджами и переключателем языка, обзор, части, подключение с рабочим примером,
архитектура, разработка, лицензия. У каждого Rust-крейта свой короткий
`README.md` рядом с `Cargo.toml`: для чего крейт, для чего нет, слой и контекст,
пример (он же doc-тест), от чего зависит. Шаблоны в
[`templates/readme/`](templates/readme/), правила в [главе 10](rust/10-readmes.md).

## Проверки

`rustfmt`, `clippy` с нашим набором линтов и порогами
([`templates/`](templates/)), `craftcheck` для того, что clippy не видит
(размеры файлов, wiring-файлы, нейминг модулей, комментарии, глобальное
состояние, слои и карта контекстов), `cargo llvm-cov` для покрытия,
`cargo mutants` для качества тестов. Подключение к существующему коду через
baseline: старые нарушения терпим, новые валят CI, baseline только уменьшается.
