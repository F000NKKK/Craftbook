# Craftbook — инженерный стандарт Rust

Универсальные инженерные принципы для библиотек, сервисов, CLI, игр, движков, ОС, встроенных устройств, настольных приложений и вычислений.

**Главная идея:** безопасность, корректность и явные контракты обязательны; DDD, Hexagonal, Clean Architecture и другие паттерны выбираются по задаче, а не навязываются всем проектам.

## Уровни требований

- **MUST** — доказуемые инварианты безопасности и корректности, публичные контракты и требования проекта.
- **SHOULD** — рекомендуемая практика; допустимо обоснованное отступление.
- **MAY** — необязательная техника или архитектурный паттерн.
- **PROJECT** — конкретные ограничения проекта: среда исполнения, производительность, совместимость, риски.

[Пример политики](templates/craftbook.toml) · [Миграция с первой версии](MIGRATION.md).

Старый `tools/craftcheck` оставлен как инструмент перехода, но его прежние жёсткие проверки не являются требованиями новой версии. Подход выбирается с учётом задачи, а не ради минимального числа строк, количества файлов или искусственной структуры слоёв.

Стандарт не гарантирует качество автоматически: он задаёт проверяемые инженерные решения и механизм их адаптации.

## Нативный инструмент на Rust (экспериментальный)

[`cargo-craftcheck`](tools/cargo-craftcheck/README.md) проверяет политику v2 без Python. Установка: `cargo install --path tools/cargo-craftcheck`. Запуск: `cargo craftcheck check --config craftbook.toml`. Сейчас проверяет только конфигурацию; анализ исходников и графа зависимостей ещё не реализован.
